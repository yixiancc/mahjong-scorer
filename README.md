# 四川麻将·血战到底计分

单文件网页计分工具，用于记录和结算四川麻将「血战到底」的每一局。

程序只负责计分，不识别牌面。每次胡牌、杠、流局由输入的人录入，程序按规则算出每家的收付。

## 快速开始

1. 下载或克隆本仓库。
2. 双击 `mahjong-scorer.html`，用浏览器打开即可。

无需安装，无需网络。CSS 已内联，页面不加载任何外部资源。

## 功能

- **记账**：点座位头像录入胡牌，选择自摸、点炮或抢杠，勾选番种特征，输入根数，标记杠上花或杠上炮。预览会显示番数、倍数和每家付款，确认后才记录。
- **杠**：明杠、补杠、暗杠。补杠可以被抢杠。
- **流局**：标记花猪或听牌，程序自动算出查大叫的金额。
- **换三张**：随机抽取方向，只作记录，不影响计分。
- **撤销**：撤销上一步，或删除任一条记录。若删除后后续记录不合法，程序会拒绝。
- **多局累计**：每局结算后自动累计总分，可一键复制总分文字。
- **设置**：基本分、方向名字、是否显示庄家，以及两个规则开关。

> **注意：数据备份**
>
> 数据保存在当前浏览器的本地存储中。换浏览器或清除站点数据，记录会丢失。
> 请定期在 **设置 → 导出 JSON** 备份，需要时用 **导入 JSON** 恢复。

## 规则

计分规则详见 [RULES.md](RULES.md)，包括番数、杠分、流局处理和验收用例。

- **范围**：只做血战到底。不做血流成河、定缺、逃跑、游戏币、坐庄与投骰、道具。
- **与原页面不同的默认值**：花猪默认不赔已胡的玩家；杠默认算一根。两项都可以在设置中修改。
- **规则来源**：[QQ 游戏四川麻将帮助页](https://game.qq.com/new05/help/smj.htm)。页面有缺漏或前后矛盾之处，RULES.md 第 9 节写明了程序采用的做法。

## 测试

RULES.md 第 8 节列出了验收用例 A–Q，覆盖自摸、点炮、杠上花、杠上炮、抢杠、一炮多响、龙七对、三家胡、流局退杠等情况。

验收用例按「基本分 = 6、杠算一根 = 否」计算，与程序默认值不同。在设置中把基本分设为 6 并关闭「杠算一根」，即可复现这些数字。

仓库内没有保留自动化测试文件。这些用例在开发时用 Node 和无界面 Edge 检查过。

## 开发

计分核心位于 `mahjong-scorer.html` 的 `/*@core-start*/` 与 `/*@core-end*/` 之间，是纯函数（事件列表 → 结算）。改规则时只改这一段，包括其中的 `DEFAULT_RULES`，并同步更新 RULES.md。
